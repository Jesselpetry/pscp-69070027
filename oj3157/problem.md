## 1. โจทย์จริงจาก iJudge

ผู้เล่นเริ่มต้นด้วยคะแนน 0 คะแนน คุณจะได้รับจํานวนเต็ม N แทนจํานวนครั้งของการกระทํา
และตามด้วยคําสั่ง N ครั้ง แต่ละคําสั่งมีได้ 2 แบบคือ
+ → เพิ่ม 10 คะแนน
- → ลด 5 คะแนน
จงเขียนโปรแกรมเพื่อจําลองเกมและหาคะแนนรวมหลังจากทําครบทุกคําสั่ง

## 2. Input Specification

บรรทัดแรก: จํานวนเต็ม N (1 ≤ N ≤ 1,000)
บรรทัดที่สองถึง N บรรทัด: มี N คําสั่ง (+ หรือ -) คั่นด้วยช่องว่าง

## 3. Output Specification

แสดงจํานวนเต็ม 1 ค่า: คะแนนรวมสุดท้าย
