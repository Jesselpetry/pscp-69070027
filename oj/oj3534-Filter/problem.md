## 1. โจทย์จริงจาก iJudge

คุณจะได้รับ Dict เป็นก้อนๆเช่นเดิม<br />
คู่ Key: Value คือ รหัสนักศึกษา: คะแนนไฟนอล // &lt;type&gt; str: float<br />
<br />
คุณจะต้องทำการ Filter นักศึกษา โดยให้แสดงผลนักศึกษาที่มีคะแนนมากกว่าหรือเท่ากับที่กำหนดไว้ให้เท่านั้น<br />
โดยให้แสดงผลรหัสนักศึกษา และ คะแนน คั่นด้วย Tab หนึ่งตัว<br />
โดยที่รหัสศึกษาที่แสดงผลนั้น ต้องแสดงผลเรียงจากน้อยไปมากด้วย<br />
<br />
ถ้าหากไม่มีนักศึกษาใดๆอยู่ในข้อกำหนดของการ Filter ให้แสดงผลว่า Nope<br />
&nbsp;

## 2. Input Specification

สองบรรทัด<br />
1: Dict ก้อนโตๆอย่างที่บอกไปข้างบน<br />
1: ปริมาณคะแนนที่ใช้ Filter<br />
&nbsp;

## 3. Output Specification

อาจจะมีได้หลายบรรทัดอย่างที่บอก หากสงสัยก็ดู Sample เอา (โดยคะแนนอยู่ในรูปทศนิยม 2 ตำแหน่ง)<br />
หรือบรรทัดเดียวคือ Nope
