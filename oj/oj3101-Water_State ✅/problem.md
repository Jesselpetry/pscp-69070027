# OJ 3101: สถานะน้ำ

> - **iJudge cp_id**: 3101 — ภาษา Python
> - **เวลาจำกัด**: 1 วินาที | **หน่วยความจำ**: 32,000 KB
> - **โน้ตจากผู้ออกโจทย์**: ฝึก if-elif-else ตรวจสอบช่วงอุณหภูมิ (range check) → สถานะน้ำ

---

## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมเพื่อหาสถานะของน้ำโดยอุณหภูมิของน้ำบ่งบอกว่าน้ำจะอยู่ในสถานะใดที่ระดับน้ำทะเล น้ำจะอยู่ในสถานะของแข็ง (solid) เมื่ออุณหภูมิอยู่ที่ 0 องศาเซลเซียส (32 องศาฟาเรนไฮต์) น้ำจะระเหยเป็นไอ (gas) ที่อุณหภูมิ 100 องศาเซลเซียส (212 องศาฟาเรนไฮต์) หากอุณหภูมิอยู่ระหว่าง 0 - 100 องศาเซลเซียส (32 - 212 องศาฟาเรนไฮต์) น้ำจะกลายเป็นของเหลว (liquid)

เขียนโปรแกรมเพื่อรับอุณหภูมิ และหน่วยอุณหภูมิ (องศาเซลเซียสคือ C หรือองศาฟาเรนไฮต์คือ F) จากนั้นแสดงสถานะของน้ำที่อุณหภูมิดังกล่าว

## 2. Input Specification

รับค่า 2 ค่าแบบขึ้นบรรทัดใหม่โดย

บรรทัดที่ 1 รับค่า: อุณหภูมิน้ำเป็นจำนวนเต็ม

บรรทัดที่ 2 รับค่า: หน่วยอุณหภูมิเป็นตัวอักษรภาษาอังกฤษ โดยองศาเซลเซียสคือ C หรือ c หรือองศาฟาเรนไฮต์คือ F หรือ f

## 3. Output Specification

แสดงผลสถานะของน้ำตามข้อมูลนำเข้าว่าเป็น solid หรือ liquid หรือ gas

### ตัวอย่างที่ 2

- **เอาต์พุต**:
