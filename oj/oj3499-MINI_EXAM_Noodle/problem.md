## 1. โจทย์จริงจาก iJudge

ให้น้อง ๆ เขียนโปรแกรมคำนวนเงินทอนสำหรับการจ่ายเงินร้านก๋วยเตี๋ยว โดยมีการรับ input 2 ค่า คือ
- ราคาก๋วยเตี๋ยว เป็นจำนวนเต็มบวก
- เงินที่น้องจ่าย เป็นจำนวนเต็มบวก

จากนั้นให้แสดงผล ตามมีเงื่อนไขเพิ่มเติมดังนี้
- ถ้าจำนวนเงินทอนเป็น 0 ( จ่ายเงินเท่ากับราคาก๋วยเตี๋ยวพอดี ) ให้แสดงผลว่า **Good!**
- ถ้าเงินที่น้องจ่ายไม่พอค่าก๋วยเตี๋ยว ให้แสดงผลว่า **Need more cash!**
- นอกเหนือจากนี้ ให้แสดงจำนวนเงินทอน เป็นจำนวนเต็มบวก

## 2. Input Specification

2 บรรทัด
- ราคาก๋วยเตี๋ยว เป้นจำนวนเต็มบวก
- เงินที่น้องจ่าย เป็นจำนวนเต็มบวก

## 3. Output Specification

1 บรรทัด ตามเงื่อนไขของโจทย์ มีความเป็นได้ได้ 3 แบบ คือ **Good!** , **Need more cash!** และ จำนวนเงินทอน เป็นจำนวนเต็มบวก
