## 1. โจทย์จริงจาก iJudge

Ticket
โรงภาพยนตร์แห่งหนึ่งมีการกําหนดราคาตั๋วเข้าชมตามอายุของผู้เข้าชมและวันในสัปดาห์โดยมี
เงื่อนไข
ดังนี้
1. เด็กอายุตํ่ากว่า 5 ปีเข้าชมฟรี (ราคา 0 บาท)
2. นักเรียน (อายุ 5–18 ปN) ค่าตั๋วปกติ 100 บาท
. ผู้ใหญ่ (อายุ 19 ปีขึ้นไป) ค่าตั๋วปกติ 150 บาท
4. โปรโมชั่นพิเศษ: ทุกวันพุธ (Wed) ทุกประเภทตั๋วลดครึ่งราคา
จงเขียนโปรแกรมเพื่อรับข้อมูลอายุและวันในสัปดาห์ จากนั้นคํานวณและแสดงผลราคาตั๋วที่ต้องชําระ

## 2. Input Specification

• บรรทัดเดียว: จํานวนเต็มแทน อายุ (ปี) และสตริงแทน วันในสัปดาห์
• อายุ: 0 ≤ age ≤ 120
• วันในสัปดาห์: Mon, Tue, Wed, Thu, Fri, Sat, Sun

## 3. Output Specification

์: • แสดงราคาตั๋วเป็นจํานวนเต็ม (บาท)
• ไม่ต้องพิมพ์ข้อความอื่นเพิ่มเติม
