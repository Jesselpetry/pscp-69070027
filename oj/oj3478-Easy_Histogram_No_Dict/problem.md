# OJ 3478: Easy Histogram No Dict

> - **iJudge cp_id**: 3478 — ภาษา Python
> - **เวลาจำกัด**: 1 วินาที | **หน่วยความจำ**: 32,000 KB

---

## 1. โจทย์จริงจาก iJudge

ช่วยพี่ราตรีหา Histogram ของ String ดังกล่าวหน่อย โดยเรียงจากตัว aA ถึง zZ และนับตัวอักษรว่ามีกี่ตัว<br />
&nbsp;

## 2. Input Specification

<strong>1 บรรทัด</strong>
<ul>
	<li>รับข้อความ</li>
</ul>

## 3. Output Specification

<strong>n บรรทัด</strong>
<ul>
	<li>แสดงตัวอักษรและจำนวนอักษรที่นับได้ <em><strong>โดยต้องเรียง (aA - zZ)</strong></em></li>
</ul>

## 4. ตัวอย่างจาก iJudge

### ตัวอย่างที่ 1
- **อินพุต**:
  ```text
  Amazon
  ```
- **เอาต์พุต**:
  ```text
  a = 1
  A = 1
  m = 1
  n = 1
  o = 1
  z = 1
  ```

### ตัวอย่างที่ 2
- **อินพุต**:
  ```text
  Ratri and Tida
  ```
- **เอาต์พุต**:
  ```text
  a = 3
  d = 2
  i = 2
  n = 1
  r = 1
  R = 1
  t = 1
  T = 1
  ```
