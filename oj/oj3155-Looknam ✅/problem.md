# OJ 3155: ลูกน้ำ

> - **iJudge cp_id**: 3155 — ภาษา Python
> - **เวลาจำกัด**: 1 วินาที | **หน่วยความจำ**: 32,000 KB
> - **โน้ตจากผู้ออกโจทย์**: ฝึก for loop วน index บน string และแทรกเครื่องหมาย ',' ทุก 3 หลัก

---

## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมเพื่อรับค่าตัวเลข ซึ่งมีค่าอยู่ในช่วงที่กำหนด คือ มีค่าตั้งแต่ 1000 ถึง 999999 โดยค่าที่รับมาจากผู้ใช้จะมีเพียงตัวเลขเท่านั้น เช่น 23456 จากนั้นให้แสดงผลลัพธ์อยู่ในรูปแบบตัวเลขที่มีเครื่องหมายลูกน้ำ ( , ) คั่น

## 2. Input Specification

รับค่าจำนวนเต็มบวก 1 จำนวน (1000 <= x <= 999999)

## 3. Output Specification

จำนวนเต็มบวกที่มีลูกน้ำคั่นในหลักที่ 3

## 4. ตัวอย่างจาก iJudge

### ตัวอย่างที่ 1
- **อินพุต**:
  ```text
  23456
  ```
- **เอาต์พุต**:
  ```text
  23,456
  ```
