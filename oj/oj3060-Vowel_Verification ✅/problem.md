# OJ 3060: การตรวจสอบสระ

> - **iJudge cp_id**: 3060 — ภาษา Python
> - **เวลาจำกัด**: 1 วินาที | **หน่วยความจำ**: 32,000 KB
> - **โน้ตจากผู้ออกโจทย์**: ฝึกตรวจสอบว่าตัวอักษรเป็นสระหรือพยัญชนะ เน้น in operator

---

## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมเพื่อรับอักขระหนึ่งตัว และตรวจสอบว่าอักขระที่ได้รับเป็นสระหรือไม่ (a, e, i, o, u) จากนั้นพิมพ์ผลลัพธ์ออกมาเป็นตัวอย่าง

## 2. Input Specification

ตัวอักษร a-z ตัวเล็กเท่านั้น 1 ตัวอักษร

## 3. Output Specification

แสดงผลว่าตัวอักษรที่รับมาเป็นสระหรือไม่ ถ้าเป็นสระแสดงผลว่า yes หากไม่ใช่แสดงผลว่า no

## 4. ตัวอย่างจาก iJudge

### ตัวอย่างที่ 1
- **อินพุต**:
  ```text
  a
  ```
- **เอาต์พุต**:
  ```text
  yes
  ```

### ตัวอย่างที่ 2
- **อินพุต**:
  ```text
  z
  ```
- **เอาต์พุต**:
  ```text
  no
  ```
