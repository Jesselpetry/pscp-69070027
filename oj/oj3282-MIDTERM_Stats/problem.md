## 1. โจทย์จริงจาก iJudge

เขียนโปรแกรมรับตัวเลขจำนวนเต็ม เป็นจำนวน n ตัว จากนั้นให้หาค่าน้อยสุด ค่ามากสุด และค่าเฉลี่ย และแสดงผลตามลำดับ

## 2. Input Specification

n + 1 บรรทัด
บรรทัดแรก รับค่าจำนวนเต็มบวก
อีก n บรรทัด รับค่าตัวเลขจำนวนเต็ม

## 3. Output Specification

3 บรรทัด 
บรรทัดแรก แสดงค่าน้อยสุด ในรูปแบบ `MIN: {ค่าน้อยสุด ทศนิยม 3 ตำแหน่ง}`
บรรทัดสอง แสดงค่ามากสุด ในรูปแบบ `MAX: {ค่ามากสุด ทศนิยม 3 ตำแหน่ง}`
บรรทัดสาม แสดงค่าเฉลี่ย ในรูปแบบ `AVG: {ค่าเฉลี่ย ทศนิยม 3 ตำแหน่ง}`
