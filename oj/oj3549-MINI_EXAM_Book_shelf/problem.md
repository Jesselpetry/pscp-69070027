## 1. โจทย์จริงจาก iJudge

บนชั้นหนังสือมีหนังสือหลายเล่ม โดยชื่อหนังสือแต่ละเล่มคั่นด้วยช่องว่าง ให้เขียนโปรแกรมนำหนังสือออกจากชั้น 1 เล่ม ตามชื่อที่กำหนด

Input (2 บรรทัด)

- บรรทัดที่ 1: ชื่อหนังสือทั้งหมดที่อยู่บนชั้น คั่นด้วยช่องว่าง
- บรรทัดที่ 2: ชื่อหนังสือที่ต้องการนำออก

Output (1 บรรทัด)

- ถ้ามีหนังสือชื่อนั้นอยู่บนชั้น: แสดงรายชื่อหนังสือที่เหลือ เรียงตามลำดับเดิม คั่นด้วยช่องว่าง
- ถ้าไม่มีหนังสือชื่อนั้น: แสดงข้อความ There are no book with that name on this shelf

หมายเหตุ

- ชื่อต้องตรงกันทั้งคำ เช่น ชื่อ is ไม่ตรงกับ this
- ถ้ามีหนังสือชื่อเดียวกันหลายเล่ม ให้นำออกแค่เล่มแรกที่เจอ

## 2. Input Specification

<u>**2 บรรทัด**</u>
บรรทัดที่ 1 : string ที่มีหลายคำโดยแต่ละคำถูกแบ่งด้วยช่องว่าง
บรรทัดที่ 2 : string ที่มีความยาวมากกว่า 0

## 3. Output Specification

<u>**1 บรรทัด**</u>
บรรทัดที่ 1 : แสดงผลลัพธ์ตามคำอธิบาย
