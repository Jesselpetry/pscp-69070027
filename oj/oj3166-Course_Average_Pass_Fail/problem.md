> - **โน้ตจากผู้ออกโจทย์**: ฝึก for loop รับคะแนน N วิชา คำนวณ average ตรวจเงื่อนไขหลายข้อ (all-pass + avg≥60)

---

## 1. โจทย์จริงจาก iJudge

ผ่านหรือไม่? ค่าเฉลี่ยรายวิชา
ให้เขียนโปรแกรมเพื่อช่วยคุณครูตรวจว่า “นักเรียนคนหนึ่งผ่านหรือไม่” โดยอ่าน
จํานวนวิชา N และคะแนน N ค่า (0–100) จากนั้นคํานวณค่าเฉลี่ยเป็นทศนิยม 1 ตําแหน่ง และตัดสิน
ผลตามเกณฑ์ต่อไปนี้:

• ทุกวิชาต้องมีคะแนนตั้งแต่ 50 คะแนนขึ้นไป
• ค่าเฉลี่ยต้องไม่น้อยกว่า 60.0 คะแนน

ให้พิมพ์ผลลัพธ์ 2 บรรทัด: บรรทัดที่ 1 เป็นค่าเฉลี่ย (ทศนิยม 1 ตําแหน่ง), บรรทัดที่ 2 เป็นคําว่า
PASS หรือ FAIL

## 2. Input Specification

บรรทัดที่ 1: จํานวนเต็ม N (1 ≤ N ≤ 1000)
บรรทัดที่ 2 ถึงบรรทัดที่ N: คะแนนจํานวนเต็ม N ค่า

## 3. Output Specification

บรรทัดที่ 1: ค่าเฉลี่ยของคะแนนทั้งหมด แสดงทศนิยม 1 ตําแหน่ง
บรรทัดที่ 2: PASS หากผ่านเกณฑ์ หรือ FAIL หากไม่ผ่าน
