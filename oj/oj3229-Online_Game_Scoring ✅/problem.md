## 1. โจทย์จริงจาก iJudge

ระบบคิดคะแนนเกมออนไลน์
น้องมิกค์เป็นนักเล่นเกมออนไลน์ ในเกมนี้ผู้เล่นจะได้คะแนนจากการทําภารกิจต่างๆ โดยจะมี
การคํานวณคะแนนรวมและแสดงผลตามระดับความสําเร็จ น้องมิกค์อยากให้คุณช่วยเขียนโปรแกรม
คํานวณผลคะแนนของเขา
ระบบคิดคะแนน
- คะแนนฐาน ได้จากการทําภารกิจหลัก
- คะแนนโบนัส ได้จากการทําภารกิจพิเศษ
- ตัวคูณ ถ้าเล่นติดต่อกันเกิน 3 วัน จะได้ตัวคูณ 1.5 เท่า
- การจัดอันดับ แบ่งตามช่วงคะแนนรวม (แสดงเป็นตัวเลข)
เขียนโปรแกรม
- คํานวณคะแนนรวม (รวม ฐาน + โบนัส + ตัวคูณ)
- แสดงรหัสอันดับตามช่วงคะแนน
- แสดงรหัสสถานะพิเศษสําหรับผู้เล่นระดับสูง
รหัสอันดับ
คะแนน ≥ 1500 รหัส 5
คะแนน ≥ 1000 รหัส 4
คะแนน ≥ 500 รหัส 3
คะแนน ≥ 200 รหัส 2
คะแนน < 200 รหัส 1
รหัสสถานะพิเศษ
ถ้าอันดับ 5 และเล่นติดต่อกัน ≥ 7 วัน รหัส 99
ถ้าอันดับ 4 และได้โบนัสคะแนน > 300 รหัส 88
ถ้าไม่มี รหัส 0

## 2. Input Specification

บรรทัดที่ 1 คะแนนฐาน 0 ≤ N ≤ 1000
บรรทัดที่ 2 คะแนนโบนัส 0 ≤ N ≤ 500
บรรทัดที่ 3 จํานวนวันที่เล่นติดต่อกัน 1 ≤ N ≤ 30

## 3. Output Specification

์: บรรทัดที่ 1 คะแนนรวม
บรรทัดที่ 2 รหัสอันดับ
บรรทัดที่ 3 รหัสสถานะพิเศษ (ถ้ามี ถ้าไม่มีให้แสดง 0)
