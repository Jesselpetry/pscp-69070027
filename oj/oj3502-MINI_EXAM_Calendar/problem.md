## 1. โจทย์จริงจาก iJudge

ให้น้อง ๆ เขียนโปรแกรมคำนวนว่าอีกกี่วันถึงจะหมดเวลาในการถอนวิชาเรียน โดยกำหนด input มี 3 บรรทัด คือ ค่า วัน เดือน ปี ที่จะนำไปคำนวน เป็นจำนวนเต็มบวก ทั้งหมด

 ซึ่ง วันสุดท้ายที่จะถอนวิชาคือวันที่ 2 ตุลาคม 2569 ( 2/10/2569 )
 
 ให้แสดงผลว่าเหลืออีกกี่วันถึงจะหมดวันถอนวิชาเรียน กรณีที่ ค่า วัน เดือน ปี เป็นช่วงเวลาหลังวันถอนไปแล้วก็ให้ตอบ 0

 หมายเหตุ: เพื่อความง่ายในการคำนวน กำหนดให้เดือนทุกเดือนในโจทย์ข้อนี้ มี 30 วัน เท่ากันหมด

## 2. Input Specification

3 บรรทัด วัน เดือน ปี เป็นจำนวนเต็มบวก ทั้งหมด โดยที่
- วัน มีค่าตั้งแต่ 1 - 30
- เดือน มีค่าตั้งแต่ 1 - 12
- ปี มีค่าตั้งแต่ 2560 - 2570

## 3. Output Specification

1 บรรทัด เป็นจำนวนเต็มบวก หรือ 0 จำนวนวันก่อนจะหมดการถอนวิชาเรียน
