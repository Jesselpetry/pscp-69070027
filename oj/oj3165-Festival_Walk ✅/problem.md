## 1. โจทย์จริงจาก iJudge

เดินเล่นในงานเทศกาล
ลานงานเทศกาลเป็นตารางพิกัด 2 มิติคุณเริ่มที่์0, 0) แล้วได้รับสตริงคําสั่งการเคลื่อนที่
ประกอบด้วย
ตัวอักษร:
• N เดินขึ้น (y + 1)
• S เดินลง (y − 1)
• E เดินขวา (x + 1)
• W เดินซ้าย (x − 1)
หลังทําตามคําสั่งทั้งหมด ให้พิมพ์พิกัดสุดท้าย (x, y) และ “ระยะแมนฮัตตัน” จากจุดเริ่ม (0,0) ซึ่งคือ
|x| + |y|

## 2. Input Specification

เป็นสตริง ประกอบด้วยตัวอักษรในชุด {N, S, E, W} เท่านั้น

## 3. Output Specification

แสดงค่าผลลัพธ์ x y ที่พิกัดสุดท้ายและ d
d คือระยะแมนฮัตตัน = |x| + |y|
