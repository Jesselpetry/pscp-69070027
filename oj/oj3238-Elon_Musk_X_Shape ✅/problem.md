## 1. โจทย์จริงจาก iJudge

lon Musk มาเองฮะ
โจทย์: วาด X-shape
คําอธิบาย: เขียนโปรแกรม รับค่า จํานวนเต็มบวก x และ ตัวอักษร k จากผู้ใช้ แล้ววาด รูป X-shape
ขนาด x × x
• ถ้า k เป็น # ให้วาดด้วยเครื่องหมาย #
• ถ้า k เป็นตัวอักษรอื่น ให้วาดด้วยตัวอักษร โดยเริ่มจาก k + x/2 และเปลี่ยนตัวอักษรตามแนวทแยง
ของ X
• ส่วนที่ไม่ได้เป็นทแยงมุม ให้พิมพ์-
ข้อจํากัด:
• 3 ≤ x ≤ 99
• x เป็นจํานวนเต็ม
• k เป็นตัวอักษร ASCII

## 2. Input Specification

บรรทัดเเรก จํานวนเต็มและตัวอักษร เช่น 5A

## 3. Output Specification

์: X-shape ดัง
