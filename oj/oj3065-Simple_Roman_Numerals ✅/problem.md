---

## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมเพื่ออ่านจำนวนเต็ม (ควรเป็น 1-9) และพิมพ์เลขโรมันของหลักนั้น โดยข้อมูลนำเข้าต้องเป็นตัวเลข 1 หลักเท่านั้นจึงจะแสดงตัวเลขโรมัน ในกรณีอื่น ๆ โปรแกรมจะแสดงผลลัพธ์ดังต่อไปนี้

ในกรณีที่ผู้ใช้ป้อนค่าลบ โปรแกรมจะแสดง "Error : Please input positive number" ในกรณีที่ผู้ใช้ป้อนค่าบวกที่อยู่นอกช่วงที่กำหนด (1-9) โปรแกรมจะแสดง "Error : Out of range"

## 2. Input Specification

จำนวนเต็ม 1 ค่า (0 <= N <= 9)

## 3. Output Specification

ถ้าเป็นเลข 1-9 จะแสดงผลเป็นเลขโรมันตามที่ข้อมูลนำเข้า

ถ้าเป็นจำนวนเต็มลบจะแสดงผล "Error : Please input positive number"

ถ้าเป็นศูนย์ และจำนวนเต็มบวกแต่ค่าอยู่นอกเหนือจากช่วง 1-9 จะแสดงผล "Error : Out of range"
