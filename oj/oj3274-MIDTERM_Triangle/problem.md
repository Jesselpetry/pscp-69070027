## 1. โจทย์จริงจาก iJudge

ครูสอนเรขาคณิตต้องการโปรแกรมช่วยตรวจการบ้านนักเรียน โดยนักเรียนจะส่งความยาวด้านทั้งสามของรูปมาให้

โปรแกรมต้องตรวจสอบสองขั้นตอน

ขั้นแรก ตรวจว่าความยาวทั้งสามด้านสามารถประกอบเป็นรูปสามเหลี่ยมได้จริงหรือไม่ ตามอสมการสามเหลี่ยม (a+b>c และ a+c>b และ b+c>a)ซึ่งกำหนดว่าผลบวกของด้านสองด้านใดๆ ต้องมากกว่า ด้านที่เหลือเสมอ หากผลบวกเท่ากันพอดีจะได้เพียงเส้นตรง ไม่ถือเป็นสามเหลี่ยม

ขั้นที่สอง หากประกอบเป็นสามเหลี่ยมได้ ให้ระบุชนิดของสามเหลี่ยมตามความยาวด้าน ดังนี้

ด้านเท่ากันทั้งสามด้าน เรียกว่า สามเหลี่ยมด้านเท่า (EQUILATERAL)
ด้านเท่ากันสองด้าน เรียกว่า สามเหลี่ยมหน้าจั่ว (ISOSCELES)
ด้านไม่เท่ากันเลยสักด้าน เรียกว่า สามเหลี่ยมด้านไม่เท่า (SCALENE)

นอกจากนี้ ครูยังต้องการทราบด้วยว่าสามเหลี่ยมนั้นเป็นสามเหลี่ยมมุมฉากหรือไม่ ซึ่งตรวจได้จากทฤษฎีบทพีทาโกรัส คือกำลังสองของด้านยาวที่สุด เท่ากับผลบวกของกำลังสองของอีกสองด้านถ้าเป็นให้ตอบ (RIGHT TRIANGLE)


- ตรวจสอบเป็นสามเหลี่ยมได้หรือไม่ก่อนเสมอ
- เช็คว่าเป็นสามเหลี่ยมด้านเท่าหรือไม่
- เช็คว่าเป็นมุมฉากหรือไม่
- เช็คว่าเป็นหน้าจั่ว หรือไม่
- เช็คว่าเป็น สามเหลี่ยมด้านไม่เท่า หรือไม่

## 2. Input Specification

<u>**รับข้อมูล 3 บรรทัด**</u>
แต่ละบรรทัดคือจำนวนเต็ม a, b, c (1 ≤ a, b, c ≤ 10,000) แทนความยาวด้านทั้งสามของรูป

## 3. Output Specification

1 บรรทัด

- หากไม่สามารถประกอบเป็นสามเหลี่ยมได้ ให้พิมพ์บรรทัดเดียวว่า `NOT A TRIANGLE`

- หากประกอบเป็นสามเหลี่ยมได้ ให้ตอบว่าเป็นสามเหลี่ยมชนิดไหนในตัวเลือกนี้ `EQUILATERAL`, `ISOSCELES`, `SCALENE`, `RIGHT TRIANGLE`
