## 1. โจทย์จริงจาก iJudge

คุณฉงนต้องการเขียนโปรแกรมโดยใช้ลูป for โดยคุณฉงนจะรับค่าจํานวนเต็ม 1 จํานวนจากแป้นพิมพ์ (N) จากนั้น ให้วน loop รับค่าตัวอักษรตัวพิมพ์ใหญ่อีกทั้งหมด n ตัว แล้วรายงานผลว่าในบรรดาตัวอักษรเหล่านั้น

- มีสระรวมทั้งหมดกี่ตัว โดยสระคือ A, E, I, O และ U
- ปรากฏสระครบทั้ง 5 ตัวหรือไม่ นั่นคือ A, E, I, O และ U ต้องปรากฏอย่างน้อยตัวละ 1 ครั้ง
![](https://miro.medium.com/v2/resize:fit:713/1*qf2V2PxpBnfqVzNhLhOA0A.jpeg)

## 2. Input Specification

<u>**n + 1 บรรทัด**</u>
**บรรทัดที่ 1:** ค่า n (จำนวนเต็มบวก)
**บรรทัดที่ 2 ถึง n:** ตัวอักษรพิมพ์ใหญ่

## 3. Output Specification

**บรรทัดที่ 1:** จำนวนสระทั้งหมด
**บรรทัดที่ 2:** มี 2 กรณี คือ YES หากปรากฏสระครบทั้ง 5 ตัว มิฉะนั้นแสดง NO
