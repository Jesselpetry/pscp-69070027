## 1. โจทย์จริงจาก iJudge

![](https://ijudge.it.kmitl.ac.th:7159/api/file/file/1728717851538_c56d89.png)


Coke กำลังมีโปรโมชั่นใหม่ จากเดิมราคาขวดละ a บาท หากนำมาฝาขวดจำนวน b ฝามาแลก จะซื้อขวดใหม่ได้ในราคา c บาท (จากเดิมราคาขวดละ a บาท โดยที่ c&lt;=a) หากต้องการ Coke จำนวน d ขวด จะต้องจ่ายเงินน้อยที่สุดเท่าไร

## 2. Input Specification

มี 4 บรรทัด<br />
บรรทัดที่ 1 ค่า a เป็นจำนวนเต็มบวกหรือศูนย์ (a &gt;= 0)<br />
บรรทัดที่ 2 ค่า b เป็นจำนวนเต็มบวกหรือศูนย์ (b &gt;= 0);&nbsp;<strong>b = 0 หมายความว่าไม่สามารถนำฝามาลดราคาได้ ทุกขวดต้องซื้อในราคา a</strong><br />
บรรทัดที่ 3 ค่า c เป็นจำนวนเต็มบวกหรือศูนย์ (c &gt;= 0, c &lt;= a)<br />
บรรทัดที่ 4 ค่า d เป็นจำนวนเต็มบวกหรือศูนย์ (d &gt;= 0)

## 3. Output Specification

มี 1 บรรทัด เป็นจำนวนเงินที่ต้องจ่ายน้อยที่สุด (เป็นจำนวนเต็มบวกหรือศูนย์)
