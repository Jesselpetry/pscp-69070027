## 1. โจทย์จริงจาก iJudge

ภาษาคาบาทาเป็นภาษาเก่าแก่ที่ใช้ในหมู่ชาวนาแถบแม่น้ำคาลาบานาลาเมื่อกว่าห้าพันปีที่แล้ว<br />
ภาษาคาบาทามีเอกลักษณ์เฉพาะตัว คือ ประกอบด้วยหน่วยเสียงเพียงสามหน่วย คือ ka, ba และ ta<br />
หากประสมหน่วยเสียงเข้ากันจะเกิดเป็นวลีหรือประโยค เช่น<br />
kabakkatatatabatakakabatata แปลว่า &quot;หูฉลามอร่อยมาก&quot;<br />
tababatakakatakababatakabatakatakaba แปลว่า &quot;อยากได้โทรศัพท์ใหม่&quot;<br />
<br />
ในภาษาคาบาทา หากหน่วยเสียง ba ต่อด้วยหน่วยเสียง ka จะเปลี่ยนเป็น bakka เช่น<br />
tatabakkakatabatakabatakabakkaka แปลว่า &quot;ยืนเงินหน่อย&quot;<br />
<br />
ให้เขียนโปรแกรมตรวจสอบว่าข้อความต่างๆ อาจเป็นข้อความในภาษาคาบาทาหรือไม่<br />
<br />
<em><u><strong>ที่มา</strong></u> การแข่งขัน TOI.A รอบประจำเดือนพฤศจิกายน 2553</em>

## 2. Input Specification

บรรทัดแรกระบุจำนวนเต็ม N (2 &lt;= N &lt;= 1000) แทนจำนวนข้อความทั้งหมด<br />
จากนั้นอีก N บรรทัด แต่ละบรรทัดระบุข้อความที่ต้องการตรวจสอบหนึ่งข้อความ<br />
แต่ละข้อความจะประกอบด้วยอักขระภาษาอังกฤษพิมพ์เล็กเท่านั้นโดยไม่มีช่องว่างคั่น<br />
ข้อความแต่ละข้อความจะยาวไม่เกิน 300 อักขระ

## 3. Output Specification

ระบุผลการตรวจสอบทั้ง N ข้อความ เรียงตามลำดับ บรรทัดละหนึ่งข้อความ<br />
โดยหากข้อความดังกล่าวอาจเป็นข้อความในภาษาคาบาทา ให้พิมพ์ yes มิฮะนั้นให้พิมพ์ no
