# OJ 3070: นับเลขคู่และเลขคี่

> - **iJudge cp_id**: 3070 — ภาษา Python
> - **เวลาจำกัด**: 1 วินาที | **หน่วยความจำ**: 32,000 KB
> - **โน้ตจากผู้ออกโจทย์**: ฝึกใช้ modulo ตรวจสอบเลขคู่/คี่ และ if-else แยกกรณี

---

## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมเพื่อรับจำนวนเต็ม 3 ตัวจากแป้นพิมพ์ จากนั้นหาว่ามีเลขคู่และเลขคี่อยู่กี่ตัว

## 2. Input Specification

ตัวเลขจำนวนเต็ม 3 ตัวแบบขึ้นบรรทัดใหม่ (-1,000 <= N <= 1,000)

## 3. Output Specification

แสดงผลว่ามี even กี่ตัว odd กี่ตัว

## 4. ตัวอย่างจาก iJudge

### ตัวอย่างที่ 1
- **อินพุต**:
  ```text
  1
  2
  3
  ```
- **เอาต์พุต**:
  ```text
  1
  2
  ```

### ตัวอย่างที่ 2
- **อินพุต**:
  ```text
  0
  -1
  2
  ```
- **เอาต์พุต**:
  ```text
  2
  1
  ```
