## 1. โจทย์จริงจาก iJudge

จงหาว่าจุดที่กำหนดให้อยู่บน Quadrant ใด หรือ อยู่บนแกน X, อยู่บนแกน Y, อยู่ที่จุด Origin

ปล. สำหรับคนที่ตกคณิต นี่คือช่วงเวลาที่ดีที่คุณจะได้ลองใช้ <strong>Searching Skill</strong> ซึ่งเป็นทักษะที่สำคัญอย่างมากสำหรับการเป็นโปรแกรมเมอร์ <strong>(A.K.A. ไป Search Google)</strong>

## 2. Input Specification

**<u>2 บรรทัด</u>**

**บรรทัดที่ 1:** จำนวนเต็ม
**บรรทัดที่ 2:** จำนวนเต็ม

## 3. Output Specification

**<u>1 บรรทัด</u>** `บอก Quadrant ที่จุดนั้นอยู่`<br />
Q1 = อยู่ที่ Quadrant 1<br />
Q2 = อยู่ที่ Quadrant 2<br />
Q3 = อยู่ที่ Quadrant 3<br />
Q4 = อยู่ที่ Quadrant 4<br />
X = อยู่บนแกน X<br />
Y = อยู่บนแกน Y<br />
O = อยู่ที่จุด Origin (0, 0)
