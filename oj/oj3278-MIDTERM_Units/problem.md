## 1. โจทย์จริงจาก iJudge

บริษัทแห่งหนึ่งพัฒนาแอปพลิเคชันแปลงหน่วยวัดความยาวไทยโบราณ ซึ่งหน่วยวัดความยาวแบบไทยโบราณมีหลายหน่วยที่สัมพันธ์กันเป็นชั้น ๆ โดยมีความสัมพันธ์ดังนี้

- 	12 นิ้ว ( NIU ) เท่ากับ 1 คืบ ( KUEP )
- 	2 คืบ ( KUEP ) เท่ากับ 1 ศอก ( SOK )
- 	4 ศอก ( SOK ) เท่ากับ 1 วา ( WA )
- 	20 วา ( WA ) เท่ากับ 1 เส้น ( SEN )

ทางบริษัทจึงอยากให้คุณพัฒนาโปรแกรมสำหรับแปลงหน่วยข้างต้น โดยรับ input 3 ค่า คือ ค่าความยาวที่ต้องการแปลง, หน่วยปลายทางและหน่วยต้นทาง

## 2. Input Specification

3 บรรทัด 
บรรทัดแรก	ค่าความยาว	จำนวนจริง	ค่าตัวเลขที่ผู้ใช้มีอยู่ อยู่ในช่วง 0 ถึง 1,000,000
บรรทัดสอง	หน่วยปลายทาง	เป็นสตริง หน่วยที่ผู้ใช้อยากได้คำตอบ	เป็น NIU, KUEP, SOK, WA หรือ SEN อย่างใดอย่างหนึ่ง
บรรทัดสาม	หน่วยต้นทาง	เป็นสตริง หน่วยของค่าในบรรทัดที่ 1	 เป็น NIU, KUEP, SOK, WA หรือ SEN อย่างใดอย่างหนึ่ง

## 3. Output Specification

แสดงผล 1 บรรทัด เป็นตัวเลขคำตอบที่ปัดเป็น ทศนิยม 4 ตำแหน่ง

"ให้ใช้การจัดรูปแบบทศนิยม 4 ตำแหน่งของภาษาโดยตรง" ไม่ต้องใช้ function หรือเขียนโปรแกรมจัดการเรื่องการปัดเศษเอง
