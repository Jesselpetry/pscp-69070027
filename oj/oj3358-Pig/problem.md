## 1. โจทย์จริงจาก iJudge

พี่เลี้ยงหมูอยู่ N คู่ ซึ่งทุกสัปดาห์พี่ต้องมาคอยดูว่าแต่ละคู่ตัวไหนมีน้ำหนักมากกว่าและ ผลรวมของน้ำหนักเป็นเท่าไร่ ซึ่งพี่ขี้เกียจมานั่งหาเองจึงอยากได้โปรแกรมที่รับจำนวนหมู N ตัว และน้ำหนักหมูแต่ละตัว W1 W2 ... W(n x 2)
โดยกำหนดว่า คู่แรกคือ (W1, W2) คู่สองคือ (W3, W4) ... คู่ที่ N คือ (W((n x 2) - 1), W(n x 2))

**<u>ตัวอย่าง : </u>** 
N = 3 คู่
W = 1 3 4 7 8 9 -> 3 คู่คือ (1, 3) (4, 7) และ (8, 9)
ค่าที่มากกว่าของแต่ละคู่คือ 3, 7 และ 9 ตามลําดับ
ผลรวมคือ 3 + 7 + 9 = 19

## 2. Input Specification

***<u>2 บรรทัด</u>***

- บรรทัดแรก : ค่า N (จำนวนเต็มบวก)
- บรรทัด 2 : น้ำหนักหมูแต่ละตัว (จำนวนเต็มบวก)

## 3. Output Specification

***<u>1 บรรทัด</u>***

- บรรทัดแรก : แสดงผลสมการของผลรวมของค่าน้ำหนัก (ถ้าเกิดมีคู่เดียวให้แสดงผลลัพท์ได้เลย)
