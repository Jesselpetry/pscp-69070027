## 1. โจทย์จริงจาก iJudge

<p>Flatten แปลว่า ทำให้แบนเรียบ</p>



<p>ในที่นี้คือเรามี List ของตัวเลข ซึ่งอาจจะมี List ของตัวเลขซ้อนอยู่ข้างในนั้น ซ้อนไปเรื่อยๆได้&nbsp;</p>

<p>ดังเช่น [5, 2, 3, [7, [10, [12, 11], 9], 20], 4]&nbsp;</p>

<p>จงทำให้ List นี้มันแบนเรียบ (มีแต่ตัวเลขอย่างเดียว) พอมันแบนแล้วก็ให้เรียงจากเลขจากมากไปน้อย<br />
<br />

## 2. Input Specification

1 บรรทัด เป็น List ที่มีตัวเลข และอาจจะมี List ของตัวเลข และ List ของตัวเลข ซ้อนๆกันไปเรื่อยๆ

## 3. Output Specification

1 บรรทัดเป็น List ที่แบนเรียบแล้ว ซึ่งมีแต่ตัวเลขเพียงอย่างเดียว และเรียงจากมากไปน้อย

## 4. ตัวอย่างจาก iJudge

### ตัวอย่างที่ 1
- **อินพุต**:
  ```text
  [5, 2, 3, [7, [10, [12, 11], 9], 20], 4]
  ```
- **เอาต์พุต**:
  ```text
  [20, 12, 11, 10, 9, 7, 5, 4, 3, 2]
  ```

### ตัวอย่างที่ 2
- **อินพุต**:
  ```text
  [3, 1, 2]
  ```
- **เอาต์พุต**:
  ```text
  [3, 2, 1]
  ```

### ตัวอย่างที่ 3
- **อินพุต**:
  ```text
  [1, [-1, [2, 1]], -5]
  ```
- **เอาต์พุต**:
  ```text
  [2, 1, 1, -1, -5]
  ```
