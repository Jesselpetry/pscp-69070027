## 1. โจทย์จริงจาก iJudge

<p><strong>วิธีจัดข้อความ:</strong> ให้พิมพ์ข้อความโดย<u>เติมช่องว่างจนยาวเท่ากับ size พอดี</u></p>
<ul>
<li><strong>left</strong> : ข้อความชิดซ้าย เติมช่องว่างต่อท้าย</li>
<li><strong>right</strong> : ข้อความชิดขวา เติมช่องว่างนำหน้า</li>
<li><strong>center</strong> : เติมช่องว่างทั้งสองข้าง ถ้าช่องว่างเหลือเป็นเลขคี่ ให้ส่วนที่เกินอยู่ทางซ้าย</li>
</ul>
<p>ตัวอย่าง size = 20, ข้อความ = Caution (ขีด | ใช้แสดงขอบจอเท่านั้น ไม่ต้องพิมพ์)</p>
<pre>
left  :|Caution             |
center:|       Caution      |
right :|             Caution|
</pre>

## 2. Input Specification

<b><u>3 บรรทัด</u></b>

<b>บรรทัดที่ 1 : </b>ขนาดของจอป้ายไฟ
<b>บรรทัดที่ 2 : </b>คำสั่งให้ข้อความชิดซ้าย อยู่กึ่งกลาง หรือทางขวา (`left`, `center`, `right`)
<b>บรรทัดที่ 3 : </b>ข้อความ โดยที่ขนาดของข้อความจะไม่ใหญ่เกินกว่า size

## 3. Output Specification

ข้อความที่จัดตำแหน่งแล้ว ความยาวเท่ากับ size ตัวอักษรพอดี (รวมช่องว่างที่เติม)
