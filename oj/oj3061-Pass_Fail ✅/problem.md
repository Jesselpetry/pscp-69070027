# OJ 3061: ผ่าน/ไม่ผ่าน

> - **iJudge cp_id**: 3061 — ภาษา Python
> - **เวลาจำกัด**: 1 วินาที | **หน่วยความจำ**: 32,000 KB
> - **โน้ตจากผู้ออกโจทย์**: ฝึก if-else ตัดสินผ่าน/ไม่ผ่านจากคะแนน — พื้นฐาน binary decision

---

## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมเพื่อรับคะแนนกลางภาคและปลายภาค โดยคะแนนกลางภาคเต็ม 50 คะแนนและปลายภาคเต็ม 50 คะแนน และพิมพ์คะแนนรวมพร้อมข้อความแจ้งว่าผ่าน (pass) หรือไม่ผ่าน (fail) เป็นตัวอย่าง (เกณฑ์การผ่านคือได้คะแนนรวมไม่ต่ำกว่า 50)

## 2. Input Specification

รับค่าตัวเลข 2 ค่าแบบขึ้นบรรทัดใหม่

## 3. Output Specification

แสดงคะแนนรวม พร้อมทั้งแสดงผลว่า pass ต่อเมื่อคะแนนมากกว่าหรือเท่ากับ 50 คะแนน และหากคะแนนรวมน้อยกว่า 50 คะแนน แสดงผลว่า fail

## 4. ตัวอย่างจาก iJudge

### ตัวอย่างที่ 1
- **อินพุต**:
  ```text
  25
  35
  ```
- **เอาต์พุต**:
  ```text
  60
  pass
  ```
