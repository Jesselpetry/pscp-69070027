# OJ 3066: เหมือนกันหมด

## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมเพื่ออ่านตัวเลข 3 ตัวและแสดงผลลัพธ์ว่า "all the same" หากตัวเลขทั้งหมดเหมือนกัน แสดงผลลัพธ์ว่า "all different" หากตัวเลขทั้งหมดต่างกัน และแสดงผลลัพธ์ว่า "neither" หากตัวเลขเหมือนกันบางตัว

## 2. Input Specification

ตัวเลข 3 ตัว (0 <= N <= 1,000) แบบขึ้นบรรทัดใหม่

## 3. Output Specification

ถ้าตัวเลขเหมือนกันทั้ง 3 ตัว แสดงผลว่า "all the same"
ถ้าตัวเลขต่างกันหมดทั้ง 3 ตัว แสดงผลว่า "all different"
ถ้านอกเหนือจากนั้นแสดงผลว่า "neither"

