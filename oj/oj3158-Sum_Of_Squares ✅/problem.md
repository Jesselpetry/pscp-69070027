## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมรับตัวเลขจำนวนเต็ม 1 จำนวน (N) จากนั้นแสดงผลรวมของเลข N ลำดับแรก แต่ละตัวยกกำลังสอง (1² + 2² + 3² + … + N²) ทางหน้าจอ เช่น ถ้ารับค่าเป็น 5 แสดงว่าโปรแกรมจะต้องแสดงผลลัพธ์เป็น 55 ซึ่งได้มาจาก 1² + 2² + 3² + 4² + 5² เป็นต้น

## 2. Input Specification

จำนวนเต็ม N ลำดับแรกที่ต้องการหาผลรวมกำลังสอง

## 3. Output Specification

แสดงผลรวมตามเงื่อนไขของฟังก์ชันเป็นจำนวนเต็ม
