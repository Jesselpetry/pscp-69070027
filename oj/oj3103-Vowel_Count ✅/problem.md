## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมโดยใช้ลูป for โดยให้รับค่าจำนวนเต็ม 1 จำนวนจากแป้นพิมพ์ (N) จากนั้นให้วน loop รับค่าตัวอักษรตัวพิมพ์ใหญ่อีกทั้งหมด n ตัว แล้วให้หานับว่ามีสระอยู่กี่ตัว (สระ คือ A, E, I, O U)

## 2. Input Specification

บรรทัดแรกเป็นตัวเลขจำนวนเต็มบวกที่บอกจำนวนของการวนรับตัวอักษรภาษาอังกฤษพิมพ์ใหญ่ n ตัว และ N บรรทัดถัดมา คือ ตัวอักษรภาษาอังกฤษพิมพ์ใหญ่ 1 ตัว ต่อ 1 บรรทัดตามจำนวน n บรรทัดที่กำหนดไว้

## 3. Output Specification

จำนวนสระที่นับได้จากข้อมูลที่รับเข้ามา
