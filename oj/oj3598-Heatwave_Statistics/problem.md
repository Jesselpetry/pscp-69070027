## 1. โจทย์จริงจาก iJudge

สถิติคลื่นความร้อน (Heatwave Stats)
อ่าน N และอุณหภูมิสูงสุดรายวัน N ค่า (°C). จัดทําสถิติและรูปแบบเอาต์พุตดังนี้:
UM, AVG, MEDIAN, MAX, MIN (ทศนิยม 2 ตําแหน่ง), ALERT (≥ 37.00), และ SORTED (เรียงพร้อม
ทศนิยม 2 ตําแหน่ง).

## 2. Input Specification

บรรทัดที่ 1 N (1..1000) บรรทัดที่ 2 N ค่าแบบทศนิยม

## 3. Output Specification

์: พิมพ์ 7 บรรทัดตามรูปแบบที่กําหนด
