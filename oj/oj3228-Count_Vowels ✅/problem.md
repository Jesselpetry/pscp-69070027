## 1. โจทย์จริงจาก iJudge

## 2. Input Specification

รับข้อความยาว 3 ตัวอักษรเป็นภาษาอังกฤษตัวพิมพ์เล็ก

## 3. Output Specification

แสดงผลจำนวนตัวอักษรที่เป็นสระ
