## 1. โจทย์จริงจาก iJudge

mart Trash Collector
โรงเรียนติดตั้งเครื่องรับซื้อขยะอัตโนมัติหลายเครื่อง เครื่องแต่ละเครื่องรับขยะหลายประเภท
ได้แก่ ขวดพลาสติก, กระป๋อง, แก้ว คุณต้องเขียนโปรแกรมเพื่อคํานวณ ปริมาณขยะรวมทั้งหมด (กก.)
ของเครื่องแต่ละประเภท รวมถึงตรวจสอบเงื่อนไขพิเศษดังนี้:
1. ถ้าเครื่องใดมี ปริมาณขยะรวมเกิน 50 กก. ให้พิมพ์ข้อความ "Overloaded"
2. ถ้าเครื่องใดมี ขยะประเภทใดเกิน 20 กก. ให้พิมพ์ "Check Type X" (X คือ Plastic, Can, หรือ
Glass ตามลําดับ)

## 2. Input Specification

บรรทัดแรก: จํานวนเครื่องรับซื้ออัตโนมัติN (1 ≤ N ≤ 10)
บรรทัดต่อไป N บรรทัด แต่ละบรรทัดประกอบด้วยตัวเลข 3 ตัว (ﬂoat) แทนปริมาณขยะ
กก. ในเครื่องนั้น ลําดับ: ขวดพลาสติก, กระป๋อง, แก้ว
0.0 ≤ ปริมาณ ≤ 100.0)

## 3. Output Specification

์: สําหรับแต่ละเครื่อง:
1. พิมพ์ปริมาณขยะรวมทั้งหมดของเครื่องนั้น (ทศนิยม 1 ตําแหน่ง)
2. ถ้าเกิน 50 กก. ให้ต่อด้วย “Overloaded”
. ถ้ามีขยะประเภทใดเกิน 20 กก. ให้ต่อด้วย “Check Type X”
คั่นด้วยเครื่องหมายคอมม่า (,) หากมีหลายข้อความ
