## 1. โจทย์จริงจาก iJudge

การเทศบาลลาดกระบังได้ซื้อป้ายไฟเลี้ยวที่ใช้สำหรับติดหลังรถรดน้ำต้นไม้บนฟุตบาท<br />
แต่เจ้ากรรมตัวควบคุมไฟดันซื้อมาผิดรุ่น ทำให้ใช้การไม่ได้<br />

จนท.จึงไว้วานให้คุณเขียนโปรแกรมแสดงผลป้ายไฟ โดยมีข้อกำหนดดังนี้<br />
k หน่วยคือความกว้างของตัวอักษรไฟเลี้ยว และ<br />
n หน่วยคือความสูงของไฟเลี้ยว มีค่าเป็นเลขคี่เท่านั้น<br />
เช่น
k = 7
n = 5<br />
ผลลัพธ์จะเป็น

&nbsp;*******
&nbsp;&nbsp;*******
&nbsp;&nbsp;&nbsp; *******
&nbsp;&nbsp;*******
&nbsp;*******

เนื่องจากว่าป้ายไฟเลี้ยวที่ซื้อมามีหลากหลายขนาด ตั้งแต่รดน้ำกระถาง ต้นกล้า ล้างถนน รดต้นไม้ที่ฟุตบาท<br />
ค่า k, n จึงมีค่าได้หลากหลายรูปแบบ<br />

## 2. Input Specification

<b><u>2 บรรทัด</u></b>

<b>บรรทัดที่ 1 :</b> <b>k จำนวนนับ</b> คือ ความกว้างของป้ายไฟ
<b>บรรทัดที่ 2 :</b> <b>n จำนวนนับ(เลขคี่)</b> คือความสูงของป้ายไฟ

## 3. Output Specification

<b><u>n บรรทัด</u></b>
