## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมโดยผู้จัดการธนาคารได้ตั้งรหัสเซฟเป็น H 4567

งานของคุณคือการเขียนโปรแกรมเพื่ออ่านตัวอักษรหนึ่งตัวและตัวเลขหนึ่งตัวจากแป้นพิมพ์และตรวจสอบรหัส โดยโปรแกรมจะต้องแสดงผลลัพธ์ดังต่อไปนี้

- หากรหัสถูกต้อง โปรแกรมจะแสดงผล "safe unlocked"
- ถ้าเฉพาะตัวอักษร H เท่านั้นที่ถูกต้อง โปรแกรมจะแสดงผล "safe locked - change digit"
- ถ้าเฉพาะค่าตัวเลขเท่านั้นที่ถูกต้อง โปรแกรมจะแสดงผล "safe locked - change char"
- ถ้ารหัสที่ป้อนผิด (ไม่ตรงกันทั้งตัวอักษรและตัวเลข) โปรแกรมจะแสดงผล "safe locked"

## 2. Input Specification

ข้อมูลเข้า: รับค่า 2 ค่าแบบขึ้นบรรทัดใหม่

บรรทัดที่ 1 รับค่า: ตัวอักษร

บรรทัดที่ 2 รับค่า: จำนวนเต็ม

## 3. Output Specification

ผลลัพธ์: แสดงผลตามเงื่อนไขของโจทย์
