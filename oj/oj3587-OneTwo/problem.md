## 1. โจทย์จริงจาก iJudge

กำหนดให้ S1, S2, ..., Sn เป็นข้อความ<br />
โดยที่<br />
S1 = &quot;1&quot;<br />
S2 = &quot;2&quot;<br />
และ&nbsp;Sn คือ Sn-1 ต่อกับ Sn-2<br />
สำหรับทุกๆ n &gt;=3 เช่น<br />
S3 คือ S2 ต่อกับ S1 คือ &quot;21&quot;<br />
S4 คือ S3 ต่อกับ S2 คือ &quot;212&quot;<br />
S5 คือ S4 ต่อกับ S3 คือ &quot;21221&quot;<br />
<br />
จงหา Sn โจทย์จาก : http://tucc.triamudom.ac.th/grader/1099

## 2. Input Specification

จำนวนเต็ม n (1 &lt;= n &lt;= 22)

## 3. Output Specification

ข้อความ Sn โดยไม่ต้องมีเครื่องหมายคำพูด
