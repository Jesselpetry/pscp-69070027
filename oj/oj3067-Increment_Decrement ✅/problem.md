# OJ 3067: การเพิ่ม/ลด

> - **โน้ตจากผู้ออกโจทย์**: ฝึก if-else กับ string input เพื่อเลือกปฏิบัติการ (+/-) กับตัวเลข

---

## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมที่อ่านตัวเลขสามตัวและพิมพ์ว่า "increasing" หากตัวเลขเหล่านั้นเรียงตามลำดับเพิ่มขึ้น พิมพ์ว่า "decreasing" หากตัวเลขเหล่านั้นเรียงตามลำดับลดลง และพิมพ์ว่า "neither" หากเรียงตามลำดับอื่น ในที่นี้ "increasing" หมายถึง การเพิ่มขึ้นอย่างแท้จริงโดยแต่ละค่าจะมีค่ามากกว่าค่าก่อนหน้า ลำดับ 3 4 4 จะไม่ถือเป็นการเพิ่มขึ้น

## 2. Input Specification

ตัวเลข 3 ตัวแบบขึ้นบรรทัดใหม่

## 3. Output Specification

ถ้าตัวเลขทั้ง 3 ตัวเรียงตามลำดับที่เพิ่มขึ้นแสดงผลว่า "increasing"

ถ้าตัวเลขทั้ง 3 ตัวเรียงตามลำดับที่ลดลง แสดงผลว่า "decreasing"

ถ้าตัวเลขทั้ง 3 ตัวเรียงตามลำดับที่นอกเหนือจากนั้นแสดงผลว่า "neither"
