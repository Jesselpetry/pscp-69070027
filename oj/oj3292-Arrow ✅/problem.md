## 1. โจทย์จริงจาก iJudge

พี่พีเป็นคนชอบใช้ลิฟท์มากๆอยู่มาวันหนึ่งหลังจากสอนน้องๆที่คณะเสร็จแล้วกําลังจะกลับบ้านพี่พีก็กดลิฟท์เพื่อที่จะลงไปชั้น 1 ตามปกติ<br />
แต่หลังจากเข้าไปในลิฟท์พี่พีก็เจอ นายพรานคนหนึ่ง (ได้ไง? เพราะเป็นโจทย์) นายพรานคนนั้นต้องการลูกธนูหลายอันมาก เพื่อที่จะไปยิงกวางในอุดมคติจึงบอกพี่พีให้ไปหามาให้ไม่งั้นพี่พีจะถูกฆ่าตาย พี่พีซึ่งไม่รู้จะทํายังไงดีจึงรีบขอความช่วยเหลือจากเทพอย่างน้องๆ preprogramming ให้ช่วยสร้างลูกธนูใน cmd เพื่อที่จะหลอกนายพรานให้พี่หน่อย<br />
<img alt="" src="https://ejudge.it.kmitl.ac.th/uploads/1561039412_lift.png" style="height:564px; width:889px" /><br />
<strong>สาระเพิ่มเติม:</strong>&nbsp;ลูกธนู เป็นสิ่งที่เคลื่อนที่แบบโพรเจกไทล์จากการยิงของธนู เป็นอาวุธระยะไกลที่ทรงประสิทธิภาพและพบได้ในทุกอารยธรรม<br />
&nbsp;

## 2. Input Specification

2 บรรทัด<br />
บรรทัดแรกเป็น String รับประกันได้ว่าจะมีแค่ตัวอักษร R กับ L เท่านั้น<br />
<span style="color:#FF0000">โดย &quot;R&quot; จะหมายถึงลูกธนูที่ชี้ไปทางขวา &quot;L&quot; จะหมายถึงลูกธนูที่ชี้ไปทางซ้าย</span><br />
บรรทัดที่สองเป็น ค่า n ซึ่งจะเป็นขนาดของลูกธนูแต่ละดอก (n &gt;= 2)<br />
&nbsp;

## 3. Output Specification

เป็นลูกธนูแต่ละดอกที่มีขนาดเท่ากับ n แต่ละดอกเว้นด้วยหนึ่งบรรทัด<br />
<span style="color:#FF0000">** ไม่ต้องสงสัยว่าทําไมลูกธนูหน้าตาแบบนี้เพราะเป็นลูกธนูในอุดมคติ **</span>
