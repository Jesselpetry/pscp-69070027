# OJ 3106: Basic ATM

> - **iJudge cp_id**: 3106 — ภาษา Python
> - **เวลาจำกัด**: 1 วินาที | **หน่วยความจำ**: 32,000 KB
> - **โน้ตจากผู้ออกโจทย์**: ฝึกจำลอง ATM: ตรวจสอบยอดเงินคงเหลือก่อนถอน ใช้ if-else compound condition

---

## 1. โจทย์จริงจาก iJudge

Basic ATM
จงเขียนโปรแกรมถอนเงินจากเครื่อง ATM ที่บรรจุธนบัตร 1000 บาท 500 บาท และ 100
บาท

## 2. Input Specification

ให้ผู้ใช้ระบุจํานวนเงินที่ต้องการถอนมีค่าไม่ตํ่ากว่า 100 บาท และไม่เกิน 20,000 บาท

## 3. Output Specification

แสดงผลออกมาว่า ใช้ธนบัตรอย่างละกี่ใบ โดยอยากให้จำนวนธนิบัตรที่ได้มีจำนวนน้อยใบที่สุด
ถ้าจํานวนเงินที่กรอกผิดพลาด ไม่สามารถถอนได้ เช่น ไม่อยู่ในช่วงที่กําหนด หรือเป็นเศษไม่เต็ม 100
ให้แสดงผล ERROR
