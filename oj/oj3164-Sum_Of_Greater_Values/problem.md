## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมที่รับจำนวนเต็มหนึ่งตัว (n) ก่อน จากนั้นโปรแกรมจะรับคู่จำนวนเต็ม n คู่ โปรแกรมจะแสดงผลรวมของค่าที่มากกว่าของแต่ละคู่ ถ้ามี 1 คู่จะแสดงผลเฉพาะค่าที่มากกว่าในคู่

ตัวอย่าง

กำหนด n = 3 คู่ของจำนวนเต็ม 3 คู่คือ (1, 3) (4, 7) และ (8, 9)

ค่าที่มากกว่าของแต่ละคู่คือ 3, 7 และ 9 ตามลำดับ

ผลรวมคือ 3 + 7 + 9 = 19

## 2. Input Specification

บรรทัดแรกประกอบด้วยจำนวนเต็ม (n)

บรรทัดที่ 2 ถึงบรรทัดที่ n:มีจำนวนเต็ม n

## 3. Output Specification

เส้นเดี่ยวแสดงผลสมการของผลรวมของค่าที่มากกว่าของแต่ละคู่ และตามเงื่อนไขของโจทย์
