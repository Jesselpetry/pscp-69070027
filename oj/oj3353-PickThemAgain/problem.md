## 2. Input Specification

หนึ่งบรรทัด<br />
ตัวเลขจำนวนเต็มที่คั่นด้วยช่องว่างหนึ่งช่อง จำนวนของตัวเลขอาจจะได้มากระดับหนึ่ง แต่ไม่น้อยกว่าหนึ่งตัว

## 3. Output Specification

อาจมีได้หลายบรรทัด แสดงผลจำนวนเต็มบรรทัดละหนึ่งตัว
