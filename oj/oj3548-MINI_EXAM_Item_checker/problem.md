## 1. โจทย์จริงจาก iJudge

สร้างโปรแกรมที่รับค่า string ที่มีชื่อสิ่งของต่างๆโดยแบ่งด้วยช่องว่างแล้วให้รับค่า string อีก 1 ค่าแล้วทำการเช็คว่ามีสิ่งของใน string ที่ 2 ใน string ที่ 1 หรือไม่ ถ้ามีให้แสดงผลว่า '(string ที่ 2) is in the list' ถ้าไม่มีให้แสดงผลว่า '(string ที่ 2) is not in the list'
*การเช็คสนแค่ว่าเป็นคำเดียวกันหรือไม่ (ไม่สนว่าเป็นตัวพิมพ์ใหญ่หรือเล็ก)

## 2. Input Specification

<u>**2 บรรทัด**</u>
บรรทัดที่ 1 : string ที่มีชื่อสิ่งของ 1 สิ่งหรือมากกว่าโดยถูกแบ่งด้วยช่องว่าง
บรรทัดที่ 2 : string ของชื่อสิ่งของที่ต้องการเช็คว่ามีหรือไม่

## 3. Output Specification

<u>**1 บรรทัด**</u>
บรรทัดที่ 1 : แสดงผลลัพธ์ตามคำอธิบายข้างต้น

## 4. ตัวอย่างจาก iJudge

### ตัวอย่างที่ 1
- **อินพุต**:
  ```text
  test 1 2 3 4
  4
  ```
- **เอาต์พุต**:
  ```text
  4 is in the list
  ```

### ตัวอย่างที่ 2
- **อินพุต**:
  ```text
  test 1 2 3 4
  5
  ```
- **เอาต์พุต**:
  ```text
  5 is not in the list
  ```

### ตัวอย่างที่ 3
- **อินพุต**:

- **เอาต์พุต**:
  ```text

  ```
