## 1. โจทย์จริงจาก iJudge

กำหนด
<ul>
	<li>เซต A มีสมาชิก n ตัว</li>
	<li>เซต B มีสมาชิก m ตัว</li>
	<li>ผลต่าง A &ndash; B คือเซตที่ประกอบด้วยสมาชิกของ A ที่ไม่ใช่สมาชิกของ B</li>
</ul>
จงหาเขียนโปรแกรมเพื่อหาสมาชิกทั้งหมดของเซต A-B ตัวอย่าง

<ul>
	<li>A = { 1 , 2 , 3}</li>
	<li>B = { 4 , 1 }</li>
	<li>A-B = { 2 , 3 }</li>
</ul>

## 2. Input Specification

บรรทัดแรกรับ n<br />
บรรทัดที่สองรับ m<br />
n บรรทัดต่อมา รับ เลขจำนวนเต็ม ซึ่งเป็นสมาชิกของ A<br />
อีก&nbsp;m บรรทัด รับ เลขจำนวนเต็ม ซึ่งเป็นสมาชิกของ B

## 3. Output Specification

สมาชิกทั้งหมดของเซต A-B เรียงลำดับจากค่าน้อยไปหามาก
