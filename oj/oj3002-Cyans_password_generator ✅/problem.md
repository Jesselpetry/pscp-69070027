# OJ 3002: Cyan's password generator

> - **iJudge cp_id**: 3002 — ภาษา Python
> - **เวลาจำกัด**: 1 วินาที | **หน่วยความจำ**: 32,000 KB
> - **โน้ตจากผู้ออกโจทย์**: ฝึกการใช้ string slicing

---

## 1. โจทย์จริงจาก iJudge

ให้น้อง ๆ ช่วยพี่ Cyan เขียนโปรแกรมเพื่อรับชื่อ นามสกุล และอายุของผู้ใช้ จากนั้นสร้างรหัสผ่านของผู้ใช้ตามเงื่อนไขต่อไปนี้

- หากชื่อและนามสกุลของผู้ใช้มีความยาวไม่ต่ำกว่าห้าอักขระ ให้สร้างรหัสผ่านโดยใช้สองอักขระแรกของชื่อของผู้ใช้ ตามด้วยอักขระสุดท้ายของนามสกุลของผู้ใช้ และหลักสุดท้ายของอายุตามลําดับ
- กรณีอื่นๆ ให้ใช้ตัวอักษรตัวแรกของชื่อจริงพร้อมอายุและตัวอักษรสุดท้ายของนามสกุลตามลําดับ

## 2. Input Specification

<u>**3 บรรทัด**</u>
**บรรทัดที่ 1:** ชื่อของผู้ใช้งาน
**บรรทัดที่ 2** นามสกุลของผู้ใช้งาน
**บรรทัดที่ 3** อายุของผู้ใช้งาน

## 3. Output Specification

**บรรทัดที่ 1** รหัสผ่านที่สร้างขึ้นมา
