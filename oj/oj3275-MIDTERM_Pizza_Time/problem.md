## 1. โจทย์จริงจาก iJudge

ชมรมคอมพิวเตอร์จัดงานเลี้ยงรุ่น มีสมาชิกเข้าร่วมทั้งหมด N คน

ประธานชมรมต้องการสั่งพิซซ่ามาเลี้ยง โดยตั้งใจว่าสมาชิกทุกคนต้องได้กินอย่างน้อยคนละ K ชิ้น

พิซซ่าที่ร้านขายเป็นถาด ถาดละ M ชิ้น และร้านขายเป็นถาดเต็มเท่านั้น ไม่ขายแยกชิ้น

จงเขียนโปรแกรมคำนวณ จำนวนชิ้นพิซซ่าที่ต้องการทั้งหมด ต้องสั่งพิซซ่ากี่ถาด และเมื่อแบ่งให้ทุกคนครบคนละ K ชิ้นแล้ว จะเหลือพิซซ่ากี่ชิ้น

## 2. Input Specification

รับข้อมูล 3 บรรทัด ดังนี้

บรรทัดที่ 1: จำนวนเต็ม N (1 ≤ N ≤ 10,000) — จำนวนสมาชิกที่เข้าร่วมงาน

บรรทัดที่ 2: จำนวนเต็ม K (1 ≤ K ≤ 100) — จำนวนชิ้นที่ต้องการให้แต่ละคนได้กินเป็นอย่างน้อย

บรรทัดที่ 3: จำนวนเต็ม M (1 ≤ M ≤ 100) — จำนวนชิ้นต่อพิซซ่า 1 ถาด

## 3. Output Specification

บรรทัดที่ 1: จำนวนชิ้นพิซซ่าที่ต้องการทั้งหมด
บรรทัดที่ 2: จำนวนถาดที่ต้องสั่ง
บรรทัดที่ 3: จำนวนชิ้นที่เหลือหลังแบ่งครบทุกคนแล้ว
