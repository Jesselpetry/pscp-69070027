## 1. โจทย์จริงจาก iJudge

จงเขียนโปรแกรมรับคะแนนแบบฝึกหัด (เต็ม 10) คะแนนกลางภาค (เต็ม 40) และคะแนนปลายภาค (เต็ม 50) และรายงานผลสอบดังนี้คือ ผ่าน (pass) กับล้มเหลว (fail) โดยนักเรียนจะผ่านการสอบได้ก็ต่อเมื่อคะแนนแต่ละส่วน (คะแนนแบบฝึกหัด คะแนนกลางภาค และคะแนนปลายภาค) ไม่น้อยกว่า 50 %

## 2. Input Specification

คะแนน 3 ส่วน คะแนนแบบฝึกหัด (เต็ม 10) คะแนนกลางภาค (เต็ม 40) และคะแนนปลายภาค (เต็ม
50) แบบขึ้นบรรทัดใหม่

## 3. Output Specification

ถ้าคะแนนทั้ง 3 ส่วนมากกว่า 50 % แสดงผลว่า pass โดยที่ถ้ามีคะแนนส่วนใดส่วนหนึ่งน้อยกว่า 50
% แสดงผลว่า fail
