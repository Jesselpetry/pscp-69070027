## 1. โจทย์จริงจาก iJudge

มาเป็นทีม
บริษัทแห่งหนึ่งต้องการสร้างโปรแกรมสําหรับเก็บคะแนนพนักงานในการทํางานเป็นทีม โดยมี
รายละเอียดดังนี้
- รับจํานวนทีม N (1 ≤ N ≤ 10)
- รับจํานวนสมาชิกในแต่ละทีม M (1 ≤ M ≤ 20)
- รับคะแนนของพนักงานแต่ละคน (เป็นจํานวนเต็ม 0 – 100) เก็บใน array 2 มิติ
- โปรแกรมต้องคํานวณและแสดงผล:
- คะแนนเฉลี่ยของแต่ละทีม
- หาค่ามากที่สุดของแต่ละทีม
- หาคะแนนรวมทั้งหมดของทุกทีม
เงื่อนไขข้อมูล
• 1 ≤ N ≤ 10
• 1 ≤ M ≤ 20
หากกรอกข้อมูลนําเข้านอกเหนือจากเงื่อนไข ให้แสดงผลลัพธ์ 1 บรรทัด โดยแสดงข้อความ Data
Incorrect
