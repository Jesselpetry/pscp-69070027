# OJ 3280: [ MIDTERM ] CODE CLEANER

## 1. โจทย์จริงจาก iJudge

> ระบบคลังสินค้าต้องแปลงข้อความบนป้ายที่พนักงานพิมพ์เข้ามา ให้เป็นรหัสสินค้ามาตรฐาน
> โดยไล่ดู **ทีละอักขระจากซ้ายไปขวา** ตามกฎนี้
>
> 1. ตัวอักษรภาษาอังกฤษ → เก็บไว้โดยเปลี่ยนเป็น**ตัวพิมพ์ใหญ่**
> 2. ตัวเลข `0`–`9` → เก็บไว้ตามเดิม
> 3. อักขระอื่นทั้งหมด (รวมช่องว่าง) → แทนด้วยขีด `-` หนึ่งตัว
> 4. **ขีดที่ติดกันหลายตัวให้เหลือเพียงตัวเดียว**
> 5. เมื่อทำครบทุกอักขระแล้ว ให้**ตัดขีดที่อยู่หน้าสุดและท้ายสุดทิ้ง**
> 6. ถ้าทำครบแล้ว**ไม่เหลืออักขระใดเลย** ให้ใช้คำว่า `NONE` เป็นรหัส
>
> พร้อมกันนั้นให้รายงานจำนวนตัวอักษรภาษาอังกฤษและจำนวนตัวเลขที่พบในข้อความ**ต้นฉบับ**

## 2. Input Specification

- **<u> บรรทัดเดียว</u>**
  
- ข้อความที่พนักงานพิมพ์ · ยาวไม่เกิน 200 อักขระ · **อาจว่างเปล่าได้**
  
- รับประกันว่าเป็นอักขระ **ASCII ที่พิมพ์ได้** เท่านั้น (ไม่มีภาษาไทยและไม่มีแท็บ)

## 3. Output Specification

3 บรรทัดเสมอ ตามรูปแบบนี้เป๊ะ (มีช่องว่างรอบ `=`)

- CODE = <รหัสที่แปลงแล้ว หรือ NONE>
- LETTERS = <จำนวนตัวอักษรภาษาอังกฤษในข้อความต้นฉบับ>
- DIGITS = <จำนวนตัวเลขในข้อความต้นฉบับ>

## 4. ตัวอย่างจาก iJudge

### ตัวอย่างที่ 1
- **อินพุต**:
  ```text
  Green Tea 500 ml.
  ```
- **เอาต์พุต**:
  ```text
  CODE = GREEN-TEA-500-ML
  LETTERS = 10
  DIGITS = 3
  ```

### ตัวอย่างที่ 2
- **อินพุต**:
  ```text
  ***   hello   world!!
  ```
- **เอาต์พุต**:
  ```text
  CODE = HELLO-WORLD
  LETTERS = 10
  DIGITS = 0
  ```

### ตัวอย่างที่ 3
- **อินพุต**:
  ```text
  !!!
  ```
- **เอาต์พุต**:
  ```text
  CODE = NONE
  LETTERS = 0
  DIGITS = 0
  ```
