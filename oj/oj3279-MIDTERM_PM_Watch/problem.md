## 1. โจทย์จริงจาก iJudge

เครื่องวัดฝุ่นหน้าอาคารบันทึกค่า PM2.5 ไว้วันละหนึ่งค่า ฝ่ายอาคารต้องการรายงานสรุปประจำเดือน โดยถือว่าวันที่ค่าฝุ่น มากกว่า 50 เป็น "วันเกินเกณฑ์" (ค่า 50 พอดี ไม่ใช่ วันเกินเกณฑ์)

รายงานประกอบด้วยสี่บรรทัด

`OVER` — จำนวนวันเกินเกณฑ์ทั้งหมด
`PEAK` — ค่าฝุ่นที่สูงที่สุดในบรรดาทุกวัน (นับทุกวัน ไม่ใช่เฉพาะวันเกินเกณฑ์)
`STREAK` — ความยาวของช่วงวันเกินเกณฑ์ที่ติดต่อกันยาวที่สุด ถ้าไม่มีวันเกินเกณฑ์เลยให้เป็น 0
`START` — วันเริ่มต้นของช่วงนั้น นับวันแรกเป็นวันที่ 1 ถ้ามีหลายช่วงที่ยาวเท่ากัน ให้รายงานช่วงที่อยู่ท้ายสุด · ถ้าไม่มีวันเกินเกณฑ์เลยให้เป็น `0`

## 2. Input Specification

N+1 บรรทัด
บรรทัดที่ 1 : N จำนวนวันที่บันทึก `1 ≤ N ≤ 100,000` (จำนวนเต็ม)
บรรทัดที่ 2 ถึง N+1 : ค่าฝุ่นของแต่ละวันเรียงตามลำดับวัน  `0 ≤ ค่าฝุ่น ≤ 1,000` (จำนวนเต็ม)

## 3. Output Specification

4 บรรทัด ตามรูปแบบนี้เป๊ะ (มีช่องว่างรอบ `=`)

- `OVER` = <จำนวนวันเกินเกณฑ์>
- `PEAK` = <ค่าสูงสุดของทุกวัน>
- `STREAK` = <ความยาวช่วงที่ยาวที่สุด>
- `START` = <วันเริ่มต้นของช่วงนั้น>
