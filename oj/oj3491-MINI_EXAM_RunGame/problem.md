## 1. โจทย์จริงจาก iJudge

![](https://ijudge.it.kmitl.ac.th:7159/api/file/file/1728720946105_c88a0e.png)


มีลู่วิ่งเป็นเส้นตรง บนลู่วิ่งมีของวางอยู่ k ชิ้น โดยของแต่ละชิ้นอยู่ที่ตำแหน่งต่างกัน

คุณเริ่มวิ่งจากตำแหน่ง 0 แล้วต้องวิ่งไปเก็บของ ตามลำดับที่ให้มา คือชิ้นที่ 1 ก่อน แล้วชิ้นที่ 2 แล้วชิ้นที่ 3 ไปเรื่อยๆ จนถึงชิ้นสุดท้าย

ให้เขียนโปรแกรมหาว่าคุณต้องวิ่งรวมกันเป็นระยะทางกี่หน่วย

Input (1 บรรทัด)

- ตำแหน่งของของทุกชิ้น เรียงตามลำดับที่ต้องเก็บ คั่นด้วยช่องว่าง
- ตำแหน่งแต่ละตัวเป็นจำนวนเต็ม (เป็นลบได้)
- อาจไม่มีของเลยก็ได้ (k = 0)

Output (1 บรรทัด)

- ระยะทางรวมที่ต้องวิ่ง เป็นจำนวนเต็มบวกหรือศูนย์

หมายเหตุ

- ถ้าต้องวิ่งย้อนกลับ ก็นับระยะทางที่วิ่งย้อนด้วย ระยะทางเป็นบวกเสมอ
- ไม่ต้องวิ่งกลับมาที่ตำแหน่ง 0 หลังเก็บชิ้นสุดท้าย

## 2. Input Specification

1 บรรทัด เป็นตำแหน่งของทั้งหมด k ชิ้น (k &gt;= 0) บนลู่วิ่งที่เป็นเส้นตรงบนเส้นจำนวน โดยแต่ละตำแหน่งเป็นจำนวนเต็มใดๆ และมีเว้นวรรคระหว่างแต่ละตำแหน่ง

## 3. Output Specification

1 บรรทัด เป็นระยะทางรวมที่ต้องวิ่ง เป็นจำนวนเต็มบวกหรือศูนย์
