มีมนุษย์คนหนึ่งชื่อ นาย ก ใช้ชีวิตอยู่ในจักรวาลคู่ขนาน ขึ้นรถโดยสารขนส่งสาธารณะเป็นประจำจนเขาสามารถทราบได้ว่าที่นั่งของเขาจะอยู่แถวที่เท่าไรและตัวที่เท่าไรของแถวนั้น

## 2. Input Specification

3 บรรทัด<br />
-บรรทัดแรกคือจำนวนที่นั่งในแต่ละแถว เป็นจำนวนเต็มบวกและเป็นเลขคู่<br />
-บรรทัดที่สองคือจำนวนแถวในรถโดยสาร เป็นจำนวนเต็มบวก<br />
-บรรทัดที่สามคือหมายเลขที่นั่งของนาย ก ซึ่งจะไม่เกินจำนวนที่นั่งทั้งหมดแน่นอน

## 3. Output Specification

ผังของรถโดยสารซึ่งแทนที่นั่งของนาย ก ด้วย XX<br />
โดยจะมีจำนวนที่นั่งไม่เกิน 99 ที่ และหากหมายเลขที่นั่งมีหลักเดียวให้เติม 0 นำหน้า<br />
ส่วนทางเดินนั้นจะเป็นบรรทัดเปล่าหนึ่งบรรทัด
