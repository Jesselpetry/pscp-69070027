## 1. โจทย์จริงจาก iJudge

คํานวณราคาสินค้าโปรโมชั่น
ห้างสรรพสินค้าชื่อดังแห่งหนึ่งจัดงาน Big Sale ต้อนรับเปิดเทอม โดยมีสินค้าสามประเภทที่
นักเรียนมักซื้อ
ได้แก่
- ดินสอ (สินค้า A) ราคา 25 บาท/ชิ้น
- สมุด (สินค้า B) ราคา 40 บาท/ชิ้น
- กล่องสี (สินค้า C) ราคา 55 บาท/ชิ้น
เพื่อดึงดูดลูกค้า ห้างได้ออกโปรโมชั่นพิเศษว่า “ถ้านักเรียนซื้อสินค้ารวมครบตั้งแต่ 3 ชิ้นขึ้นไป
จะได้ส่วนลด 10% จากยอดรวมทั้งหมดทันที”
จงเขียนโปรแกรมรับจํานวนสินค้าที่นักเรียนซื้อมาทั้ง 3 ประเภท และแสดงราคาสุทธิที่ต้องจ่าย
ออกมา

## 2. Input Specification

จํานวนเต็ม 3 ค่า a b c
- a = จํานวนดินสอ
- b = จํานวนสมุด
- c = จํานวนกล่องสี
0 ≤ a,b,c ≤ 1000)

## 3. Output Specification

์: ราคาสุทธิ (จํานวนเต็ม ปัดเศษลงหลังจากคิดส่วนลด)
