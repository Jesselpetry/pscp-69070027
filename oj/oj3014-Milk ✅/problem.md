## 1. โจทย์จริงจาก iJudge

ณ ฟาร์มโคนมแห่งนึงในประเทศวันเดอร์แลนด์ ได้มีการตั้งราคาและโปรโมชันสำหรับการขายนมวัวที่เปลี่ยนไปมาไม่ซ้ำกันในแต่ละวันขึ้นกับความพึงพอใจของเจ้าของฟาร์ม ซึ่งนั่นทำให้เจ้าของฟาร์มเองก็มีความสับสนว่าถ้าลูกค้าจ่ายเงินมาเท่านี้ลูกค้าจะได้นมวัวกลับไปกี่ขวดกันแน่? แต่ก็ไม่อยากตั้งราคาที่แน่นอน เพราะความอินดี้ส่วนตัวของเจ้าของฟาร์มและถือเป็นจุดขายของฟาร์ม(?)ด้วย จึงมาขอร้องให้คุณเขียนระบบง่ายๆที่รับราคานมต่อขวด ขวดละ<strong> a</strong> บาท โดยมีโปรโมชันคือนำฝาขวดทุกๆ&nbsp;<strong>b</strong> ฝา จะสามารถแลกนมได้<strong> c</strong>&nbsp;ขวด และหากลูกค้ามีเงิน&nbsp;<strong>d&nbsp;</strong>บาทจะได้รับนมสูงสุดกี่ขวด

## 2. Input Specification

<b><u>4 บรรทัด</u></b>

<b>บรรทัดที่ 1 : </b> a {a > 0}
<b>บรรทัดที่ 2 : </b> b {b >= 0; b = 0 หมายความไม่มีโปรโมชั่นนี้ ไม่สามารถนำฝาไปแลกได้}
<b>บรรทัดที่ 3 : </b> c {c >= 0 and c < b เมื่อ b != 0}
<b>บรรทัดที่ 4 : </b> d {d >= 0}

## 3. Output Specification

<b><u>1 บรรทัด</u></b>

<b>บรรทัดที่ 1 : </b>แสดงจำนวนนมขวดทั้งหมดที่ลูกค้าจะได้รับ
