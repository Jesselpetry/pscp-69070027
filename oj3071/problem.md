## 1. โจทย์จริงจาก iJudge

กําหนดให้ A และ B เป็นจํานวนนับ โดยที่ A < B
ให้ว่ามีจํานวนนับ x ในช่วง [A , B] กี่จํานวน ที่หารด้วยจํานวนนับ d แล้วเหลือเศษ r

## 2. Input Specification

บรรทัดที่ 1 จํานวนนับ A :
บรรทัดที่ 2 จํานวนนับ B : (โดยที่ B > A)
บรรทัดที่ 3 จํานวนนับ d (ตัวหาร) :
บรรทัดที่ 4 จํานวนนับ r (เศษ) : (โดยที่ r < d)

## 3. Output Specification

บรรทัดที่ 1 : จํานวนข้อมูลที่สอดคล้อง N :
