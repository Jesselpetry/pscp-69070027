## 1. โจทย์จริงจาก iJudge

คุณต้องการสร้างสะพานความยาว goal นิ้ว

โดยคุณมีอิฐก้อนเล็กอยู่ `a ก้อน` โดยอิฐก้อนเล็กจะมีความยาว `1 นิ้ว`

และคุณมีอิฐก้อนใหญ่อยู่ `b ก้อน` โดยอิฐก้อนใหญ่จะมีความยาว `5 นิ้ว`

ให้หาว่าเมื่อนำอิฐมาต่อกันสร้างเป็นสะพาน
จะต้องใช้อิฐก้อนเล็กน้อยที่สุดกี่ก้อน

โดยเราจะใช้อิฐก้อนใหญ่ให้ได้มากที่สุดก่อนจะใช้อิฐก้อนเล็กเสมอ
โดยต้องสร้างให้พอดีกับ goal นิ้ว ถ้าก้อนใหญ่มีเกิน ก็ให้ใช้เท่าที่ใช้ได้ แล้วนำก้อนเล็กมาโปะ

## 2. Input Specification

**<u>3 บรรทัด</u>**

จำนวนเต็มบวก 3 จำนวน จำนวนละ 1 บรรทัด<br />

**บรรทัดที่ 1:** ตัวแปร a
**บรรทัดที่ 2:** ตัวแปร b
**บรรทัดที่ 3:** ตัวแปร goal

## 3. Output Specification

**<u>1 บรรทัด</u>**

จำนวนอิฐก้อนเล็กที่ต้องใช้
ถ้าไม่สามารถสร้างได้ ตอบ -1
