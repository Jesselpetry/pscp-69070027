## 1. โจทย์จริงจาก iJudge

<p>ให้รายการของจุดบนระนาบจำนวน N จุด (1 &lt;= N &lt;= 100) แต่ละจุดระบุด้วยพิกัดบนแกน x และพิกัดบนแกน y ที่เป็นจำนวนเต็ม ไม่มีคู่ของจุดใด ๆ ที่อยู่ที่ตำแหน่งเดียวกัน</p>

<p>เราต้องการเรียงจุดเหล่านี้ตามค่าจากฟังก์ชัน f ที่นิยามว่า f(x,y) = x + y จากน้อยไปมาก</p>

<p>ถ้ามีจุดที่มีค่าฟังก์ชัน f เท่ากัน ให้เรียงโดยให้จุดที่มีค่าพิกัดบนแกน y มากกว่ามาก่อน<br />
<br />
<em><strong>ที่มา การแข่งขัน&nbsp;Thailand Code Jom 2014 Qualification Round</strong></em></p>

## 2. Input Specification

<p>บรรทัดแรกระบุจำนวนเต็ม T (1 &lt;= T &lt;= 5) แทนจำนวนชุดข้อมูลทดสอบ จากนั้นจะมีข้อมูลทดสอบ T ชุดตามลำดับ</p>

<p>ข้อมูลทดสอบแต่ละชุดจะอยู่ในรูปแบบดังนี้</p>

<ul>
	<li>บรรทัดแรกระบุจำนวนเต็ม N (1 &lt;= N &lt;= 100)</li>
	<li>อีก N บรรทัดระบุข้อมูลของจุด แต่ละบรรทัดจะระบุจำนวนเต็มสองจำนวน X และ Y (-10000 &lt;= X &lt;= 10000; -10000 &lt;= Y &lt;= 10000)</li>
</ul>

## 3. Output Specification

สำหรับแต่ละชุดข้อมูลทดสอบให้พิมพ์จุดที่เรียงแล้วตามลำดับที่ระบุในโจทย์
