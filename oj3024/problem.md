## 1. โจทย์จริงจาก iJudge

ระบบให้คะแนนนั้นสามารถให้ได้ตั้งแต่ 0 ถึง 10 คะแนน เ<u>ป็นจำนวนจริง</u>
เมื่อโหวดกันเสร็จแล้ว ระบบจะแสดงเพียงคะแนนรวม และคะแนนสูงสุดเพียงค่าเดียว

ถ้าคะแนนโหวดของคนที่ให้คะแนนสูงสุด และคะแนนต่ำสุดห่างกันเกินสองคะแนน จะทำให้คนมาดูคะแนนรู้สึกประหลาดใจ (Surprising) และพาคิดไปว่า มันต้องมีหน้าม้ามาอวยแน่ๆ!!

ระบบเว็ปจึงต้องมีการแจ้งว่า มีโอกาสที่จะเกิด Surprising หรือไม่ที่หน้ารีวิวสินค้า

`Surprising` ถ้ามีโอกาส
``Not surprising`` ถ้าไม่มีโอกาส

## 2. Input Specification

**<u>2 บรรทัด</u>**

## 3. Output Specification

**<u>1 บรรทัด</u>**
**บรรทัดที่ 1:** "Surprising" หรือ "Not surprising"
