## 1. โจทย์จริงจาก iJudge

[แก้ไขโจทย์]
ในระบบคอมพิวเตอร์ สีสันต่างๆ ที่เราเห็นบนหน้าจอเกิดจากการผสมแสงสีแม่สี 3 สีเข้าด้วยกัน ได้แก่ สีแดง (Red), สีเขียว (Green) และ สีน้ำเงิน (Blue) หรือที่เรียกกันว่าระบบสี RGB โดยค่าความเข้มของแต่ละสีจะถูกแทนด้วยตัวเลขจำนวนเต็มตั้งแต่ 0 (ไม่มีสีนั้นเลย หรือมืดสนิท) ไปจนถึง 255 (สว่างสว่างที่สุด)

เมื่อเราต้องการนำสี 2 สีมาผสมกันเพื่อให้เกิดเป็นสีใหม่ วิธีที่ง่ายที่สุดในทางคณิตศาสตร์คือการหา "ค่าเฉลี่ย" ของความเข้มสีแต่ละช่อง (Channel) ดังนั้น ภารกิจของคุณคือการเขียนโปรแกรมเพื่อรับค่าสี RGB ของสีตั้งต้น 2 สี แล้วคำนวณหาค่าสีใหม่ที่เกิดจากการผสมกัน นะจ้ะ

![](https://ijudge.it.kmitl.ac.th:7159/api/file/file/1789667772055_4f68a0.png)

## 2. Input Specification

บรรทัดที่ 1: ตัวเลข 3 ตัว คั่นด้วยช่องว่าง แทนค่า R, G, B ของสีที่ 1

บรรทัดที่ 2: ตัวเลข 3 ตัว คั่นด้วยช่องว่าง แทนค่า R, G, B ของสีที่ 2

## 3. Output Specification

บรรทัดที่ 1: ตัวเลขผลลัพธ์การผสมสี R, G, B จำนวน 3 ตัว คั่นด้วยช่องว่าง โดยไม่ต้องมีข้อความอื่นปะปน
