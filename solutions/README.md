# solutions/

Finished reference code, one folder per problem id: `solutions/oj<id>/main.py`.

Folder names carry the id only — no title, no ✅ — so they never move when a
problem is renamed or passes on iJudge. Your own working copy lives on the
`main` branch under `oj/` or `oj<id>/`; this folder is the archive.

Refresh it from `main` with `python3 scripts/archive_solutions.py` (see
`scripts/README.md`).
