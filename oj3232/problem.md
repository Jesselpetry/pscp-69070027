## 1. โจทย์จริงจาก iJudge

กบน้อยกระโดด
เจ้ากบน้อยกําลังจะกระโดดไปข้างหน้า โดยครั้งแรกกระโดดได้ระยะ X เมตร แต่ละครั้งถัดไป
กระโดดได้ลดลงครั้งละ 2 เมตรกระโดดต่อไปเรื่อย ๆ จนกว่าจะถึงระยะ Y เมตร หรือมากกว่า
จงเขียนโปรแกรมเพื่อหาว่า เจ้ากบน้อยต้องใช้การกระโดดอย่างน้อยกี่ครั้ง จึงจะไปถึงเป้าหมายที่
ระยะ Y เมตร ถ้าไปไม่ถึง ให้พิมพ์ -1

## 2. Input Specification

บรรทัดเดียว: จํานวนเต็ม X และ Y
1 ≤ X ≤ 1000
1 ≤ Y ≤ 100000

## 3. Output Specification

จํานวนครั้งกระโดดขั้นตํ่าที่ทําให้ระยะรวม ≥ Y หรือ -1 ถ้าไปไม่ถึง
